## Live announcements

- **Live announcements (screen readers)**: state changes of the canvas are read in a polite region. A live failure of an agent ("Agent X failed") or a live permission request ("Agent X is waiting for permission") is read in a separate assertive region (with its session in the All view); a failed tool call ("Tool Bash failed for agent X") stays in the polite region. None of these is ever folded into a summary, but one pass reads at most three of them and then "and N more failures or permission requests" (N is exact). Only an agent heard from by a live event is announced as it happens; a state read from a history (replay after a reload, a session switch, an import) is told as "last known state: failed", is not urgent and counts in the summary like any other change. Beyond four other changes in one pass they are summarised ("N agent graph updates", real transitions only); messages between agents are counted apart ("N messages sent between agents", the number of new messages the links report, not the few that are listed). **Settings > Screen reader announcements > Announcement level** chooses how much is said, and is remembered in this browser with the other preferences. "Every change" (the default) is the behaviour above. "Important only" reads only live failures (agent or tool) and live permission requests: starts, completions, teammate activity, messages between agents and the last known states read from a history are not read out (they stay in the outline and the panels). A live failure of an agent and a live permission request are read at both levels, never summarised and never dropped; the cap of three sentences and the exact "and N more" apply to both. The roughly twelve polite live regions are not merged (not covered yet): the setting changes what the canvas announces, not which regions exist.

- **Session in the announcement (#613)**: the polite status region is in the interface language and each session name inside it is marked `lang="en"` (a name is data, the French voice does not spell it). The "All sessions" selection is interface text, not a name: it is translated (*Toutes les sessions*) and read in the language of the region, not marked English.
