## Language

Settings > Appearance > **Language** (a native select, so it works with the keyboard and screen readers) offers *Automatic (browser language)*, *Français* and *English*. The choice applies at once, is kept in this browser only (local storage, never sent to the relay) and "Automatic" forgets it. Each language is written in its own language, and `lang` is set on the translated blocks so a screen reader pronounces them correctly.

The interface is translated step by step. Each translated surface is one bullet under the **In your language** heading of the file of its domain, so translating one more surface touches only that file. For now the language covers the surfaces listed there and those named in « Translated since #613 » at the end of this page (the Conversation pill, notifications, presentation badge, `ChromeAnnouncer`, toast and keyboard help, which have no bullet of their own yet):

To add a string, add its key to the file of its domain in `web/lib/messages/`, in **every** locale (fr and en side by side; `web/lib/messages.ts` only assembles the domains, #612); `scripts/messages.test.ts` fails on a missing key, a different `{placeholder}`, a French text that is still the English one or a key defined in two domain files. `web/tests-a11y/i18n-no-mixed-languages.test.tsx` renders Settings (each notification state, an invalid threshold included), the canvas controls, the Sessions panel (columns, agent rows in each state, the announcement of agents that stop reporting), the agent card, the command palette, the legend, the context menu (canvas and agent, confirmation included), the playback bar (live, offline, demo, review, confirmation, truncated history) the shortcuts dialog, the Conversation panel (pill, tabs, search, pair filter, every kind of message and of tool call, copy feedback), the Files & repeats panel (files, conflicts, steps, repeated reads and their summary, empty and incomplete states) the Context panel (files, issues, capabilities, resume, pull requests, every state) and the Timeline panel (every state of a block and every fixed label, the table view, Sequence, the messages and their cap, the pair filter, the empty and the incomplete states, the canvas drawing itself) in each locale and fails on any rendered string (visible text, accessible names, tooltips, descriptions) that is not a value of the current locale's catalog or of an explicit allowlist of proper names and symbols; a subtree that stays English is left out only if it carries the `data-i18n-exempt` attribute, and it declares `lang="en"` as well. The guided tour (card, offer, buttons, every step) and the titles of the panels are rendered by the same test, with no exemption and no allowlist of their own. When you translate a new surface, add it to that test. Still English for now: the sentences of the graph outline, of the canvas marks it mirrors and of the hidden-panels notice (only the name of the Files & repeats panel in them follows the language, so the name is the same everywhere, WCAG 3.2.4), the words drawn by the canvas for the Cost overlay (*Unattributed*, *BY TOOL*, the qualifiers *at least*, *estimated*, *incomplete* and the unit *ctx tokens* of the header) and for the Stats overlay (*3 tools · 1:05*), the Markdown file of a conversation export, the tool detail popup and the presentation subtitle (the caption of a transition, *orchestrator: Thinking → Complete*, and its name). Translated since #613: the accessible name of the Conversation pill (*Ouvrir le panneau Conversation. Dernier message utilisateur de main :* in French, then the preview of the message: the name now comes from two hidden elements, the sentence in the interface language and the preview declaring `lang="en"` like every message text, so a screen reader that honours `lang` inside a name built with `aria-labelledby` reads the message in English and the sentence in French; not every one does (the `lang` of the elements a name is built from is not exposed everywhere), and no reader was tested here, so this is the declaration, not a promise of the voice; the visible role, agent and preview are all in it), the text of the native notifications (browser and VS Code, see Notifications: same facts and qualifiers, composed by the page, shown as received by the extension), the presentation-mode badge (*Mode présentation · V pour arrêter*, named *Arrêter le mode présentation*) and its announcement (*Mode présentation activé* / *désactivé*, *Plein écran activé* / *désactivé* for full screen), the whole live region of the page that reads the connection, session and review mode aloud (the `ChromeAnnouncer`, which declares the interface language: *Connexion : en direct. Mode direct*, the connection state with the words of the top bar, the review instruction naming the button as the bar does, *Reprendre en direct*; a session name is data: it sits in its own element declaring `lang="en"`, so the French voice does not read it), the toast "No events to review yet" (*Aucun événement à revoir pour l’instant*, the same catalog sentence as the reason linked to the Review button; the toast "Review mode - press LIVE to resume" no longer exists: review mode is announced once, by that region) and the keyboard help the graph reads to screen readers (generated from the same table as the shortcuts dialog, in the language: *Flèches : Se déplacer entre les nœuds…*). The play button and its shortcut use the same words (*Lecture* / *Pause*, *Lecture / pause*). The playback-bar badge uses the words of the top bar (LIVE, OFFLINE, DEMO become EN DIRECT, HORS LIGNE, DÉMO) and pulses only while the relay is watching, in both languages. The Cost and Stats overlays are left in English on purpose (#373): their drawing functions (`drawCostSummaryPanel`, `drawStatsOverlay`) take no language, the Cost panel is a box of a fixed width whose header wraps from a measured width (`costHeaderWraps`), and the width of the Stats box is reserved by the overlay plan from the measured English text (`statsLabel`). A French text is longer (*au moins … estimé … jetons ctx*), so translating them would change measured widths that decide wrapping and label placement, and no measurement was made. The Cost figures keep their French equivalent in the *Totaux du coût* text region. To translate them later, the draw would have to receive the locale and the measures be redone in French at 320 px and at 200 % zoom.
To add a language, extend `LOCALES` and fill the table.
