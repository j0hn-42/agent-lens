## Hide inactive and what it hides

- **Hide inactive** ([#372](https://github.com/j0hn-42/agent-lens/issues/372)): one toggle of the top bar (row 1, after Notifications) and of **Settings > Sessions and presentation** replaces the former **Hide inactive agents** and **Show finished sessions**, which used two different thresholds. On (the default, the button is pressed and underlined), it applies exactly the two filters the code already had, nothing new: it hides the agents whose turn is over or that finished (idle at the end of a turn, complete, archived, or a member that reported done; an agent idle between two steps, in error or waiting for a permission stays, and so do the members of a workflow that still runs), and, in **All sessions**, the sessions marked finished whose last event is older than 10 minutes (the selected session and the sessions of a team at work stay; a session never marked finished is never hidden, however long it is silent). Off, every agent and every session is shown. The label, "Hide inactive" (*Masquer les inactifs*), gives no time window: the agents have none, only the session filter of All sessions has one, the 10 minutes of `ACTIVE_WINDOW_MS`, which the tooltip states. The accessible name is short and names only what the view hides: "Hide inactive: agents and sessions" in All sessions, "Hide inactive: agents" in one session or a team (*Masquer les inactifs : agents et sessions*, *Masquer les inactifs : agents*); the tooltip gives the rule for that view and what Off does. In All sessions, while it hides finished sessions, the button says how many: its description and its tooltip read "Finished sessions hidden: N" (*Sessions terminées masquées : N*), the count the former "Show finished sessions (N)" carried, taken from the same sessions the filter leaves out (in the project scope when one is chosen); nothing is said when none is hidden, when the filter is off or outside All sessions. The button keeps its place in the Tab order whatever its state and the view. A choice made with the two former settings is kept: only their default pair (inactive agents hidden, finished sessions not shown) becomes On; any other pair asked to see something they hid, so it becomes Off and nothing you chose to see disappears. The **Active only** filter of the Sessions panel is a different list filter (below), not this one.
- **Blank canvas after "Hide inactive"**: when every agent of the view is finished and the filter hides them all, the canvas says "N finished agents hidden" with a "Show" button that turns the filter off (it then shows every agent and every session). It appears only when each hidden agent is finished (an idle agent hidden too would make the count wrong), so the number is exact.
